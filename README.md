I am a **4th-year Information Technology student** bridging the gap between clean application code, reliable network infrastructure, and intelligent embedded systems.

I build responsive web applications while strengthening my knowledge of routing, switching, Linux, automation, IoT, and hardware-software integration.

My long-term goal is to become a:

* 🌐 **Network Automation Engineer**

* 🔌 **Embedded Systems Engineer Soon**

## 🔬 Active Projects and Lab Experiments

### 💻 1. Full-Stack Web Applications

**What I am building:** Interactive, user-focused web platforms using **Vanilla PHP** for secure backend logic and modern interfaces built with **React** and **Tailwind CSS**.

**Current focus:**

* React state management
* PHP object-oriented programming
* Database CRUD operations
* REST API development
* Authentication and authorization
* Clean separation between frontend and backend

---

### 🌐 2. Local Network Simulation

**Platform:** Cisco Packet Tracer

**Objective:** Building functional Local Area Networks to understand how data moves between computers, switches, routers, and servers.

**What I am practicing:**

* Connecting end devices through managed switches
* Designing and configuring LAN topologies
* Solving subnetting requirements
* Assigning static IP addresses
* Configuring router interfaces through Cisco CLI
* Testing connectivity using `ping` and simulation mode
* Using commands such as `no shutdown`, `ip address`, and `show ip interface brief`

---

### 🔌 3. Beginner Embedded Systems and IoT Projects

**Objective:** Learn how software interacts with sensors, microcontrollers, networks, and physical devices.

**Projects I plan to build:**

* ESP32 temperature and humidity monitoring system
* Smart plant-watering system
* Soil-moisture monitoring system for AgriTech
* Wi-Fi-enabled home sensor dashboard
* Motion-detection security alert system
* Vehicle temperature and battery monitoring prototype
* Sensor data dashboard using PHP, MySQL, and React

**Current learning areas:**

* ESP32 and Arduino fundamentals
* Basic electronic components
* Digital and analog input/output
* Sensors, relays, LEDs, and motors
* C and C++ programming
* Serial communication
* Wi-Fi and Bluetooth communication
* MQTT and HTTP-based IoT communication
* Designing simple enclosures using Autodesk Fusion
