### 🔬 Active Projects & Lab Experiments

#### 💻 1. Full-Stack Web Applications
* **What I'm building:** Interactive, user-centric web platforms utilizing **Vanilla PHP** for secure backend logic and modern UI structures built with **React** and **Tailwind CSS**.
* **Focus areas:** State management, database CRUD operations, and clean code separation.

#### 🌐 2. Local Network Simulation (Cisco Packet Tracer)
* **Objective:** Building functional Local Area Networks (LAN) to understand how data moves across hardware.
* **What I'm doing:**
  * Connecting End Devices via managed Switches.
  * Resolving **Subnetting** constraints and assigning static IP addresses.
  * Configuring Router interfaces via CLI using commands like `no shutdown` and `ip address`.
